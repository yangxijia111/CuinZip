# CuinZip 快速上手

## 第一次打开

1. 使用便携版时，右键下载的 ZIP，选择 Windows 的“全部解压”。
2. 打开解压后的文件夹，双击 **CuinZip.exe**。请保留旁边的 **x64** 文件夹。
3. 使用安装版时，安装完成后从开始菜单打开 **CuinZip**。

建议把软件放在固定文件夹。升级时先关闭 CuinZip，再把新版完整解压到新的文件夹。
安装版在原位置升级时会兼容旧版本的启动入口，之前选过的打开方式仍可打开新版。

## 解压一个压缩包

1. 在首页点击 **解压压缩包**，选择 ZIP、7z 或 RAR 等压缩包。
2. 确认“解压到”文件夹。如果包有密码，输入密码。
3. 点击 **解压**，等待完成。原压缩包会保留。

也可以先点 **打开压缩包** 查看内容，再点工具栏上的 **解压**。
分卷压缩包需要所有分卷位于同一个文件夹，并选择第一个分卷，例如 `资料.7z.001`。

## 把文件打包

1. 在首页点击 **创建压缩包**。
2. 点击 **添加文件** 或 **添加文件夹**，把要打包的项目加入列表，再点 **下一步**。
3. 确认压缩包的保存位置和名称。一般分享文件可选择 **ZIP**；需要更高压缩率时可选择 **7z**。
4. 点击 **确定**，等待完成。“更多选项”可设置压缩级别、分卷和加密等。

文件夹可以拖到首页创建压缩包，也可以从文件管理器选中文件夹后点 **添加**。
首次使用建议保留默认设置。需要密码保护时，请牢记密码；工具无法找回丢失的密码。

## 双击压缩包用 CuinZip 打开

安装版会把 CuinZip 加入 Windows 的候选打开应用。打开 CuinZip 的
**设置 → 文件关联 → Windows 默认应用设置**，找到 **CuinZip**，
按需为 `.zip`、`.7z` 等格式选择 CuinZip。安装本身不会改变已有默认应用。

便携版可右键压缩包 → **打开方式 → 选择其他应用**，浏览到 **CuinZip.exe**。
如果 Windows 提供“始终使用此应用”选项，可自行勾选。之后请保持软件文件夹位置不变。

## 常见问题

- **提示文件不完整**：重新完整解压软件 ZIP。不要直接在 ZIP 预览中运行，也不要单独移动 CuinZip.exe。
- **找不到压缩包**：检查文件是否已移动或删除，可从首页重新选择。
- **密码错误**：核对大小写与空格；请向压缩包的提供者确认密码。
- **文件已存在**：首次解压建议选择一个新的空文件夹，避免覆盖已有文件。
- **压缩包损坏**：先 **打开压缩包**，再点工具栏上的 **测试**；测试失败时重新下载，分卷包检查是否缺少分卷。
- **资源管理器没有 CuinZip 右键菜单**：便携版和普通安装版通过应用内操作；Explorer 扩展由 MSIX 版提供。

软件来自 NanaZip 和 7-Zip，保留它们的许可证与署名。当前版本为未签名预览版。
